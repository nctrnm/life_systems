# Problem Diagnosis

The Problem module helps users define friction before trying to solve it.

In Life Systems, a problem is not treated as a vague feeling, complaint, or inconvenience. It is defined as a structured relationship between four variables:

`Problem = f(Trigger, Context, Conflict, Impact)`

If one or more variables are missing, the issue may still matter, but it is not ready for full resolution yet.

## The Four Variables

### 1. Trigger

The catalyst that starts the friction.

### 2. Context

The baseline environment, rules, constraints, and current conditions.

### 3. Conflict

The point where opposing forces collide.

### 4. Impact

The cost of doing nothing.

## Purpose

This module helps users avoid solving the wrong problem. By defining the issue clearly, the user can move into complexity mapping, decision analysis, execution, and audit with a more accurate starting point.
