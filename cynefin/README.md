# Complexity Mapping

## Attribution

This module adapts concepts from the Cynefin framework, which is associated with Dave Snowden, Cognitive Edge, and The Cynefin Company. Life Systems does not claim ownership of Cynefin, its original domain model, or its terminology. This module uses Cynefin as a credited sense-making reference within the broader Life Systems methodology.

The Complexity Mapping module helps users choose the right response style for the situation.

Not every problem should be handled the same way. Some problems are simple and need a known fix. Some require analysis. Some require experiments. Some require immediate stabilization before deeper analysis is possible.

Life Systems adapts the Cynefin sense-making model into an everyday decision architecture.

## Domains

### 1. Clear

The trigger is obvious and the context is stable.

**Method:** Sense → Categorize → Respond  
**Use:** Apply known best practices.

### 2. Complicated

The trigger is not obvious, but it can be found through expertise, research, or analysis.

**Method:** Sense → Analyze → Respond  
**Use:** Investigate before acting.

### 3. Complex

The situation is dynamic and cause and effect are only clear in retrospect.

**Method:** Probe → Sense → Respond  
**Use:** Run small, safe-to-fail experiments.

### 4. Chaotic

The situation is unstable and immediate action is required.

**Method:** Act → Sense → Respond  
**Use:** Stabilize first, analyze later.

### 5. Confusion

The domain is unclear.

**Method:** Deconstruct  
**Use:** Break the issue into smaller parts until the parts can be classified.

## Purpose

This module prevents mismatched responses. It helps users avoid overanalyzing simple problems, oversimplifying complex ones, or delaying action during urgent situations.
